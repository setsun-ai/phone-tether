# phone-tether

Телефон сам включает раздачу интернета по Ethernet после каждой перезагрузки. Плюс Telegram-бот, который работает через 5G самого телефона.

## Установка: одна команда

В **Termux** (из F-Droid):

```sh
curl -fsSL https://raw.githubusercontent.com/setsun-ai/phone-tether/main/install.sh | sh
```

Скрипт сам ставит пакеты, скачивает код, включает автозапуск и спрашивает токен бота.
Chat id он узнаёт сам: просто напиши боту что угодно. Root он тоже определяет сам.

**Обновление:** та же команда или `/update` в боте.

## Руками в телефоне (один раз)

**Приложения:**
- [ ] Termux, **Termux:Boot**, Termux:API из F-Droid. Termux:Boot открой один раз после установки.
- [ ] MacroDroid (Google Play), он нужен, если нет root.

**Настройки:**
- [ ] Блокировка экрана: **Нет**. Иначе после перезагрузки ничего не запустится, пока не введёшь PIN.
- [ ] Обслуживание устройства → Автооптимизация → выключи **«Перезапуск при необходимости»** и **«Автоперезапуск»**.
- [ ] Батарея → Ограничения фонового использования → **«Никогда не переходят в спящий режим»**: добавь Termux, Termux:Boot, MacroDroid.
- [ ] Для тех же трёх приложений: Приложения → Батарея → **Без ограничений**.

**Макрос в MacroDroid** (если нет root):
- **Триггер:** «Получен интент» (Intent Received), действие `home.tether.ON`
- **Действия:**
  1. Экран вкл.
  2. Запуск ярлыка: Настройки → «Мобильная точка доступа и модем». Или Send Intent → Activity, пакет `com.android.settings`, класс `com.android.settings.TetherSettings`.
  3. Ожидание 2 с.
  4. Взаимодействие с UI → Нажать по тексту `Ethernet`.
  5. Ожидание 1 с.
  6. Взаимодействие с UI → Домой.
- MacroDroid попросит Спец. возможности: включи.
- Триггер «Загрузка устройства» **не добавляй**. Когда включать, решает tetherd.

**Проверка:** перезагрузи телефон и ничего не трогай. Через 1–2 минуты бот напишет «🔄 запущен», потом «✅ раздача работает».

## Команды бота

`/status` `/tether` `/pause` `/resume` `/log` `/update` `/reboot` (только root) `/id`

## Если не работает

- `python ~/phone-tether/tetherd.py --check` покажет, что видит демон.
- `python ~/phone-tether/tetherd.py --enable` сделает одну попытку включить раздачу.
- Лог лежит в `~/.tetherd/tetherd.log`.
- Тонкие настройки можно дописать в `~/.tetherd/config.json`, значения по умолчанию в `parse_config` в `tetherd.py`:
  - `iface_regex`: имя интерфейса;
  - `switch_label`: подпись переключателя;
  - `settings_components`: экран настроек;
  - `check_every_s`.

Root на Galaxy M15 не нужен. На One UI 8 его сделать нельзя, а на One UI 7 он стирает все данные и навсегда ломает Knox.
